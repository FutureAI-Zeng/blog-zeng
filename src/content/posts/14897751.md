`Arthas` 是Alibaba开源的Java诊断工具，深受开发者喜爱。在线排查问题，无需重启；动态跟踪Java代码；实时监控JVM状态。

- Github: https://github.com/alibaba/arthas
- 文档: https://arthas.aliyun.com/doc/

　　下载`arthas-boot.jar`，再用`java -jar`命令启动：

```
wget https://arthas.aliyun.com/arthas-boot.jar ; java -jar arthas-boot.jar
```

`arthas-boot`是`Arthas`的启动程序，它启动后，会列出所有的Java进程，用户可以选择需要诊断的目标进程。

![](/images/1110857-20210618230019337-1282111345.png)

 选择需要监控进程前的序号，输入 `1` ，再`Enter 回车，便会打印 arthas 的banner`：

![](/images/1110857-20210618230137326-420826646.png)

 　　输入 help 可以查看 arthas 的所有命令：

![](/images/1110857-20210618230358346-588418528.png)

## Dashboard

`dashboard` 命令可以查看当前系统的实时数据面板。分为三个部分：第一部分为cpu监控，第二部分为内存监控，第三部分为环境信息

![](/images/1110857-20210618230451971-1246972229.png)

 　　输入 `q` 或者 `Ctrl+C` 可以退出dashboard命令。

　　还可以使用指定的方式启动，在浏览器web页面进行访问服务器的arthas 控制台：

```
指定arthas 服务所在的ip地址：--target-ip 112.25.26.68   
指定arthas 服务访问的端口及监听的服务进程：  --telnet-port 3658 19113
```

```
java -jar arthas-boot.jar --target-ip 112.25.26.68 --telnet-port 3658 19113
```

## Jad

可以通过 `jad` 命令来反编译代码.查看当前jvm 中类的代码。此命令在项目发布定位某个类信息有没有更改过来时，使用这个命令可以很快定位代码是否修改。

![](/images/1110857-20210620230605351-1708666979.png)

## Watch

通过`watch`命令可以查看函数的参数/返回值/异常信息。

### 退出Arthas

用 `exit` 或者 `quit` 或者 stop  命令可以退出Arthas。
