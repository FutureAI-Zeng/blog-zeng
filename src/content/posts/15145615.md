　　1. 下载 redis 安装包并解压：https://redis.io/download

# 安装gcc

yum install gcc

```
　wget https://download.redis.io/releases/redis-6.2.5.tar.gz  
  
 tar xzf redis-6.2.5.tar.gz
 cd redis-6.2.5
 # 进行编译与安装
 make
```

　　2. 修改配置

```
daemonize yes #后台启动
protected‐mode no #关闭保护模式，开启的话，只有本机才可以访问redis
```

# 需要注释掉bind

#bind 127.0.0.1（bind绑定的是自己机器网卡的ip，如果有多块网卡可以配

　　3. 启动服务

```
src/redis‐server redis.conf　　或 　　　　src/redis-server
```

　　4. 验证是否启动成功 ： ps -ef|grep redis

![](/blog-zeng/images/1110857-20210815232855400-355718486.png)

　　5. 进入 redis 客户端

```
  # 进入redis客户端
  src/redis‐cli

  # 退出客户端
  quit
```

# 退出redis服务：

src/redis‐cli shutdown
