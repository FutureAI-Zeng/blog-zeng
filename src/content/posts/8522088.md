2.2 更改class路径

右键项目，Java Build Path -> Source

下面应该有4个文件夹。src/main/java，src/main/resources，src/test/java ，src/test/resources。

双击每个文件夹的Output folder，选择路径。

src/main/java，src/main/resources，选择target/classes;

src/test/java ，src/test/resources, 选择target/test-classes;

选上Allow output folders for source folders.（如果没有选上的话）

![85d08a77-0e84-4c7e-be6f-4cdd3a8225d8](https://images2015.cnblogs.com/blog/897393/201602/897393-20160224150744177-1119994583.png "85d08a77-0e84-4c7e-be6f-4cdd3a8225d8")
