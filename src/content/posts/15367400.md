转载请注明出处：

　　服务器上使用docker 安装启动 nacos 的时候，报 The container name "/nacos" is already in use by container 异常，其具体信息如下：

![](/blog-zeng/images/1110857-20211004220711778-1021705011.png)

 　　解决方案：

　　1。 查看所有的 docker 容器。

```
docker ps -a
```

　　该命令可以查看所以启动过的容器（包含已停止及正在运行的docker 容器）

![](/blog-zeng/images/1110857-20211004220935725-466264819.png)

 　　2. 移除已存在的容器

```
docker rm containerId
```

![](/blog-zeng/images/1110857-20211004221336726-949354731.png)

　　3. 使用docker 重新启动nacos

```
docker run -d  --name nacos -p 8848:8848 --env MODE=standalone --env NACOS_SERVER_IP=112.125.26.68 nacos/nacos-server
```

![](/blog-zeng/images/1110857-20211004221454738-2042928564.png)

　　4. 可以正常访问：

![](/blog-zeng/images/1110857-20211004221533796-1298221015.png)
