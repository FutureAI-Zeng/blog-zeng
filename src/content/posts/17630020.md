## 1.查看当前系统上已安装的Python版本：

　　在终端中运行以下命令：

```
python --version
```

　　或者使用以下命令查看全部已安装的Python版本：

```
ls /usr/bin/python*
```

![](https://img2023.cnblogs.com/blog/1110857/202308/1110857-20230814222918059-330999043.png)

## 2.下载并安装python包

### 2.1 下载安装包

　　访问Python官方网站 https://www.python.org/downloads/source/ ，找到并下载所需版本的源代码压缩包（例如Python 3.9.7版本对应的源代码文件为：Python-3.9.7.tgz）

　　根据官网的下载链接，此处下载python 3.2.5 的安装包，使用wget 进行下载

```
wget https://www.python.org/ftp/python/3.2.5/Python-3.2.5.tgz
```

　　如果知道版本，可以直接替换上面的版本号，替换之后使用wget进行下载

### 2.2 下载之后并解压：

```
tar -zxvf Python-3.2.5.tgz
```

　　执行过程如下：

![](https://img2023.cnblogs.com/blog/1110857/202308/1110857-20230814223402655-1492601227.png)

### 2.3进入源码目录进行配置和编译：

　　执行以下命令进行配置并编译安装Python（可以根据实际需求添加或修改参数）：配置编译选项，指定 Python 安装的目标文件夹路径。

```
./configure --prefix=/usr/local/python3.2.5
```

　　该命令的具体含义：

- `./configure`: 运行名为 `configure` 的脚本，负责根据系统环境和配置选项生成 Makefile 文件，以便后续编译和安装过程可以按照指定的选项进行。
- `--prefix=/usr/local/python3.2.5`: 指定了安装目录的路径，这里是 `/usr/local/python3.2.5`。通过设置 `--prefix` 参数，可以将 Python 安装到指定的路径中。在此示例中，Python 将被安装到 `/usr/local/python3.2.5` 目录下。

#### 2.3.1 在运行以上的配置的命令时报错，提示没有c编译器，由于是使用ubuntu系统，进行安装c编译器（如果环境没有遇到此报错，忽略此步骤）

![](https://img2023.cnblogs.com/blog/1110857/202308/1110857-20230814224918565-55964259.png)

 　　安装c编译器：

```
sudo apt-get install build-essential
```

### 2.4 存在c编译器之后，进行编译，并编写hello world

```
make && sudo make install
```

 　　安装完成之后，输入 python3，进入python3的编程终端
