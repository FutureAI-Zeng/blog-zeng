# 1.配置数据源

![](/blog-zeng/images/1110857-20231023215957525-1300884977.png)

配置完成后，点击Save And Test，如果配置正确，页面则显示如下：

![](/blog-zeng/images/1110857-20231023220311167-256486563.png)

# 2.配置dashboard

![](/blog-zeng/images/1110857-20231023220349455-1926789172.png)

点击 Add new panel 后，界面如下：

![](/blog-zeng/images/1110857-20231023220447954-613539011.png)

**按照图中的步骤，选择数据库、选择查询的数据表、构建查询的sql，最后再调整 dashboard 相关显示的样式、数值单位等等。**

# 3.配置坐标值单位

另外可以选择折线图中展示坐标轴的数值单位：

　　在这个里面可以选对应的数值的单位符号，如：百分号、温度、度数等等

![](/blog-zeng/images/1110857-20231023220719155-769204185.png)

# 4.配置sql的条件查询：

![](/blog-zeng/images/1110857-20231023220837710-822116267.png)

 配置 sql 查询的where 条件。这边在 dashboard 显示的时候会自动进行查询。
