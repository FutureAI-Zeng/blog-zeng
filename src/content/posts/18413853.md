**转载请注明出处：**

1. **查看数据库列表**

   ```
   show dbs
   ```
2. **查看当前数据库**

   ```
   db
   ```

   **![](https://img2024.cnblogs.com/blog/1110857/202409/1110857-20240914135046055-1645436303.png)**
3. **查看集合列表**

   ```
   show collections
   ```
4. **查看数据库的状态**

   ```
   db.stats()
   ```

   **![](https://img2024.cnblogs.com/blog/1110857/202409/1110857-20240914135236537-1700692314.png)**
5. **查看集合的状态**

   ```
   db.collectionName.stats()
   ```

   **这个命令会返回名为`users`的集合的详细状态信息，包括文档数量、存储大小等。**

   **![](https://img2024.cnblogs.com/blog/1110857/202409/1110857-20240914135312524-395177297.png)**
6. **查看当前连接数**

   ```
   db.serverStatus().connections
   ```

   **![](https://img2024.cnblogs.com/blog/1110857/202409/1110857-20240914135345968-917246716.png)**
7. **查看数据库的操作统计**

   ```
   db.serverStatus().opcounters
   ```

   **该命令用于查看 MongoDB 服务器的操作计数器，包括插入、更新、删除、查询等操作的次数**

   **![](https://img2024.cnblogs.com/blog/1110857/202409/1110857-20240914135425777-1210646019.png)**
8. **查看内存使用情况**

   ```
   db.serverStatus().mem
   ```

   **该命令用于查看 MongoDB 服务器的内存使用情况，包括驻留内存、虚拟内存、映射内存等。**

   **![](https://img2024.cnblogs.com/blog/1110857/202409/1110857-20240914135504717-1360713155.png)**
9. **查看当前运行的操作**

   ```
   db.currentOp()
   ```

   **10.查看集群状态角色**

   ```
   db.adminCommand({isMaster: 1})
   ```

   ![](https://img2024.cnblogs.com/blog/1110857/202409/1110857-20240918101915198-1013872380.png)
