# 1.包依赖下载：

1. **包的安装**：

　　　　Python 的包管理主要通过 pip 命令来完成。例如，要安装 requests 包，可以使用以下命令：

```
   pip install requests
```

　　　　在某些情况下，可能需要使用特定版本的包，或者从特定的源安装包。这时，你可以在 `pip install` 命令后面添加 `-i` 参数来指定源，或者在包名后面添加 `==` 和版本号来指定版本。例如：

```
pip install -i https://pypi.douban.com/simple requests==2.23.0
```

　　　　这个命令会从豆瓣的 PyPI 镜像源安装 requests 包的 2.23.0 版本。

　　2. **包的更新**

　　　　要更新一个已经安装的包，你可以使用 `pip install --upgrade` 命令。例如，要更新 requests 包，可以使用以下命令：

```
   pip install --upgrade requests
```

　　　　这个命令会将 requests 包升级到最新版本。 

# 2.查看包依赖：

　　Python 的包通常会有一些依赖，你可以使用 pipdeptree 工具来查看一个包的所有依赖。首先，你需要安装 pipdeptree：　　

```
pip install pipdeptree
```

　　然后，可以使用 `pipdeptree` 命令来查看一个包的所有依赖：

```
pipdeptree -p requests
```

　　![](/blog-zeng/images/1110857-20231113232401917-2056588537.png)

　　这个命令会显示 requests 包的所有依赖，以及它们的版本号。你可以将这些依赖和版本号复制到一个 requirements.txt 文件中，然后使用 `pip download` 命令来下载这些依赖：

```
pip download -r requirements.txt
```

# 3.查看本地的依赖库包列表

```
pip list
```

# 4.python脚本语法检查

　　1.**使用`py_compile`模块**：

　　　　`py_compile`模块可以检查Python脚本的语法，但是它不会检查代码的风格或者其他的问题。你可以使用以下命令来检查脚本的语法：

```
python -m py_compile script.py
```

　　在这个命令中，`python -m py_compile` 是检查Python脚本语法的命令，`script.py` 是想要检查的脚本。

　　2.**使用`pylint`工具**：

　　　　`pylint`是一个静态代码分析工具，它可以检查Python脚本的语法，风格问题，代码质量等问题。你可以使用以下命令来安装`pylint`：

```
pip install pylint
```

　　　　然后，你可以使用以下命令来检查脚本的语法：

```
pylint script.py
```

　　　　在这个命令中，`pylint` 是检查Python脚本语法的命令，`script.py` 是你想要检查的脚本。
