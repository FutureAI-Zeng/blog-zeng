# 欢迎

这是我的个人博客第一篇示例文章。

- 写作采用 Markdown，支持 **分类**、**多标签** 与 **归档**
- 评论与点赞由 **Giscus** 提供（数据存在 GitHub Discussions）
- 阅读量由 **Vercount** 统计

点击文章里的 `#标签` 或顶部分类/标签/归档，即可按主题筛选文章。
