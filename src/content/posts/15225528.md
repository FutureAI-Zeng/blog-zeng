## maven常用命令：

　　1. mvn clean 　　maven清理

　　2. mvn compile 　　maven 编译

　　3. mvn package　　　　maven 打包

　　4. mvn test　　　　maven执行测试用例

　　5. mvn clean compile　　同时执行 清理加编译

　　6. mvn dependency:tree　　　　展示pom的依赖关系树

idea 中配置maven编译打包忽略Test扫描的命令 : mvn clean install -DskipTests -f pom.xml
