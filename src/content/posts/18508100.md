1. **使用 `npm config get registry` 命令：**

   ```
   npm config get registry
   ```

   ![](/blog-zeng/images/1110857-20241027112655709-1529515390.png)

    显示当前配置的默认注册表地址。
2. **使用 `npm config list` 命令：**

   ```
   npm config list
   ```

   ![](/blog-zeng/images/1110857-20241027112630330-1803885562.png)

   **列出所有的 npm 配置，包括注册表设置。**
3. **使用 `npm config get` 命令查看特定的配置：**

   ```
   npm config get registry
   npm config get proxy
   npm config get https-proxy
   ```

   ![](/blog-zeng/images/1110857-20241027112555922-776804346.png)
4. **使用 `npm info` 命令：**

   ```
   npm info registry
   ```

                ![](/blog-zeng/images/1110857-20241027112354858-389672002.png)

　　　　显示当前使用的注册表信息。

 　　5. **检查 `npm config edit` 输出：**

            运行 `npm config edit` 会打开一个文本编辑器，可以直接查看和编辑配置。

                       ![](/blog-zeng/images/1110857-20241027112907814-2055391257.png)
