安装步骤：

　　可使用该文中的步骤进行安装，已经过本人验证，是可以安装成功的：

https://blog.csdn.net/doubleqinyan/article/details/80492421

　　安装之后，使用telnet命令进行测试：其语法为：telnet ip 端口号

```
telnet 172.17.215.163 22
```

执行之后会打印：

![](https://img2020.cnblogs.com/blog/1110857/202009/1110857-20200902224309253-785828511.png)

 　　当执行结果为以上时，表示对该ip的端口进行连通

　　会提示：Escape character is '^]'.

　　“^”是Ctrl键的意思！  
　　1、这个提示的意思是按`Ctrl + ]`会呼出telnet的命令行！  
　　2、telnet命令行出来后，就可以执行telnet命令了；

　　3、退出telnet命令行的名为`quit`。
