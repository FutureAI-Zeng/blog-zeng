　　1. 选中远程仓库，并fork 指定的项目到自己的私仓：

![](https://img2020.cnblogs.com/blog/1110857/202108/1110857-20210830225146017-638732718.png)

 　　fork 之后，打开我的仓库便能看到刚刚fork 的项目。

2. clone 项目代码到自己电脑的本地仓库：

　　git checkout -b dev 创建并切换至dev分支

3. 配置本地仓库的远程配置：配置本地仓库地址及远程仓库地址

```
origin 为自己仓库地址，upstream 为远程仓库地址
```

```
git remote add upstream http://github/remote/test.git
git remote add origin http://github/self/test.git
```

　　查看本地仓库远程配置命令：

```
git remote -v
```

 　　修改远程仓库配置：

```
git remote set-url origin http://xxx.com/test.git
```

4. 修改文件并提交到远程仓库：

```
git add changed_file     
git commit -m"message"   # 添加文件到暂存区然后提交，写入相应信息
git push origin dev:dev  # 这时你的远程库将会多出一个dev分支
```

5. 创建 pull request

　　在你的远程库中点击create pull request，就可以等待别人review你的代码后merge入上游仓库了

6.更新远程仓库代码到本地：

　　将远程仓库的dev分支代码更新到本地的dev分支

```
git pull upstream dev:dev
```
