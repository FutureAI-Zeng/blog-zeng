1.下载 jdk 在 Linux 环境的安装包。可以在官网下载，

　　　　官网连接：https://www.oracle.com/java/technologies/javase/javase-jdk8-downloads.html

　　但由于官网下载需要登录，没有注册还需要注册，将自己的 Linux jdk 安装包地址分享于此：

**链接：https://pan.baidu.com/s/1-nJXhvP-1v-XUe1T1ZdPzg**   
**提取码：k1nn**

　2.将安装包上传到指定目录，我这里上传到 /opt/config/jdk 目录下

3.上传成功后解压安装包：

```
tar -zxvf jdk-8u161-linux-x64.tar.gz
```

**4.配置环境变量：在当前安装目录下，编辑系统配置文件**

```
vim /etc/profile
```

　　在该配置文件中增加以下配置：

```
### JAVA_HOME 为自己指定的jdk安装目录    
export JAVA_HOME=/opt/config/jdk/jdk1.8.0_161
export CLASSPATH=$:CLASSPATH:$JAVA_HOME/lib/ 
export PATH=$PATH:$JAVA_HOME/bin
```

![](/images/1110857-20210103225132670-534319840.png)

　5.刷新环境变量文件：

```
source /etc/profile
```

![](/images/1110857-20210103225236132-440441384.png)

6.查看jdk 安装版本命令：

```
java -version
```
