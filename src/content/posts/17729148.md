转载请注明出处：

1. 使用`docker ps`命令列出正在运行的Docker容器，并获取目标容器的ID或名称。
2. 使用`docker stats <容器ID或名称>`命令来实时监测指定容器的资源使用情况。该命令将显示容器的CPU利用率、内存使用量、网络流量等信息。

   例如，要查看名为`my_container`的容器的资源使用情况，可以运行以下命令：

   ```
   docker stats my_container
   ```

   命令执行后，将连续显示容器的资源使用情况，按下`Ctrl + C`可以停止输出。

　　　 示例如下：![](https://img2023.cnblogs.com/blog/1110857/202309/1110857-20230925232820583-1960584552.png)

　　3.以非实时方式获取容器的资源使用情况，可以使用`docker stats`命令的`--no-stream`选项。这样，命令将打印一次当前的资源使用情况，然后退出。

　　例如，要打印名为`my_container`的容器的当前资源使用情况，可以运行以下命令：

```
docker stats --no-stream my_container
```
