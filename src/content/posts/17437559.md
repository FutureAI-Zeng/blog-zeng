转载请注明出处：

　　1.从Docker Hub下载MySQL镜像：

```
docker pull mysql
```

　　2.运行MySQL容器，并将主机的3306端口映射到容器的3306端口：

```
docker run -p 3306:3306 --name mysql -e MYSQL_ROOT_PASSWORD=your_password -d mysql
```

　　其中，`--name mysql`指定容器的名称为mysql，`-p 3306:3306`将容器的3306端口映射到主机的3306端口，`-e MYSQL_ROOT_PASSWORD=yourpassword`设置MySQL的root用户密码，`-d mysql`指定使用MySQL镜像并以后台模式运行容器。

　　3.使用MySQL客户端连接到MySQL容器：

```
docker exec -it mysql mysql -uroot -p
```

　　输入密码后即可进入MySQL命令行界面，进行数据库操作。

　　上面的命令可以拆分为两步：第一步进入 mysql 容器，第二步登录 mysql，命令如下：

```
docker exec -it mysql bash
mysql -uroot -p
```
