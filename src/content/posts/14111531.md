导入新项目到 idea 的时候，由于依赖的环境以及项目中 maven 编译所依赖的pom的版本不同，很多时候导入到idea的时候

maven Plugins 会出现报红的情况，这是由于maven仓库中所依赖的 jar 没有更新到本地。

　　解决方法：

　　　　1.进行maven仓库，删除临时更新文件，在maven仓库目录下搜索 lastUpdate ,然后全删。

　　　　2.根据 plugins 中报错的jar，在Lifecycle 中找到对应的功能，然后右键 Run Maven Build

![](https://img2020.cnblogs.com/blog/1110857/202012/1110857-20201209230815791-560008165.png)

　　3.然后在 maven projects 中，右键对应的项目模块，重新 Reimport 就可以了。

![](https://img2020.cnblogs.com/blog/1110857/202012/1110857-20201209230956067-1542382006.png)

　　4.如果以上都没解决，在 maven 源中央仓库中，手动下载jar，然后更新到对应的maven 仓库路径，然后重新Reimport
