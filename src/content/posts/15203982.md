　　1. 配置本地 gitee 的配置：

```
git config --global user.name "xiangBaxiang"
git config --global user.email "xxxx@user.noreply.gitee.com"
```

　　2. 创建 git 仓库，并创建 README.md 文件进行提交远程仓库

```
mkdir test2
cd test2
git init
touch README.md
git add README.md
git commit -m "first commit"
git remote add origin https://gitee.com/xiangbaxiang/test2.git
git push -u origin master
```

　　当提交到远程时，会手动弹出输入用户名和密码：

　　3. 如果远程仓库已存在：( 在gitee 管理页面手动创建代码仓库，并设置仓库属性)

```
cd existing_git_repo
git remote add origin https://gitee.com/xiangbaxiang/test2.git
git push -u origin master
```
