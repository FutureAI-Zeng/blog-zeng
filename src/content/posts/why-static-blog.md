# 为什么选择静态博客

静态博客有几个明显好处：

1. **零运维成本**：托管在 GitHub Pages，免费且稳定。
2. **速度快**：纯 HTML，Lighthouse 轻松满分。
3. **数据可控**：评论存在自己的仓库里，不依赖第三方广告平台。

```js
console.log('Hello, static blog!');
```

配合 Giscus 与 Vercount，静态站点也能拥有完整的互动与统计能力。
