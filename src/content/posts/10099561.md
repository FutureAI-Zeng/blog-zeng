解决办法：在get数据时进行为空数据判断，即可解决该问题

```
@Column(name = "band")
    public Double getBand() {
        return band == null ? Double.valueOf(FucdnNumConstant.NUM_0.getNum().doubleValue()) : band;
    }

    public void setBand(Double band) {
        this.band = band;
    }
```
