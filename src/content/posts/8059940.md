本文为博主原创，转载须注明转载地址：

方法为：

```
 tooltip : {
                            trigger: 'axis',
                            formatter: '{a0}:{c0}%'
                        },
                        legend: {
                            data:['测试']
                        },
```

此效果为：在提示框的数据添加%号
