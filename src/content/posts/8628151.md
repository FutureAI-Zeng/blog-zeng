## **启动项目**

**1、创建 `HelloController.java`**

![9](//img-blog.csdn.net/20170531220818502?watermark/2/text/aHR0cDovL2Jsb2cuY3Nkbi5uZXQvZ2ZkNTRnZDVmNDY=/font/5a6L5L2T/fontsize/400/fill/I0JBQkFCMA==/dissolve/70/gravity/SouthEast)

```
package com.example.demo;

import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController 
@RequestMapping("/hello")  
public class HelloController {
    @RequestMapping("/sts")
    public String helloworld(){  
        return "使用spring-tool-suite插件";  
    }  
}
```
