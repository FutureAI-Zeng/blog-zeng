Mobaxterm版本为20.2

1. 去除限制步骤1  
   下载 github 上面的一个开源小项目

   ```
   git clone https://github.com/flygon2018/MobaXterm-keygen.git
   ```

   下载下来后
2. ```
   cd MobaXterm-keygen
   python3 MobaXterm-Keygen.py <UserName> <Version>
   ```

   **UserName 我填的是windows的登录用户名，Version 填自己安装的版本即可，比如我填的是 20.2。 运行命令后，会生成一个 Custom.mxtpro 文件，将该文件复制到 mobaxterm 的安装根目录即可。**
