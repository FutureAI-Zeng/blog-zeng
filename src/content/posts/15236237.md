转载请注明出处：

　　 若服务器安装 jdk 时用的是root 用户，则root 用户登录服务器可以直接获取Java环境。 当切换到其他子用户时，则会发现环境不存在，命令不存在等。

　　解决方案：

　　　　1. 先切换到java 安装时的用户，并对java 的安装文件配置 用户组权限：对其他用户，当前用户等添加读写执行权限：

```
　chmod 777 *
```

　　　　2. 复制jdk 安装用户的java 环境变量配置。切换到子用户，对子用户的配置添加环境配置：

```
vi ~/.bash_profile
```

　　　　将安装用户的java 环境变量配置添加到上面操作文件的最下面，以我的服务器配置示例如下：

```
export JAVA_HOME=/opt/config/jdk/jdk1.8.0_161
export CLASSPATH=$:CLASSPATH:$JAVA_HOME/lib/
export PATH=$PATH:$JAVA_HOME/bin
```

　　　　保存退出

　　　　3. 刷新资源文件，使配置生效：

```
source ~/.bash_profile
```

　　　　4. 查看java 环境是否配置成功

```
java -version
```
