# 元素隐藏

在html中我们经常需要把某些元素隐藏起来，有时候我们需要临时隐藏页面，让其他元素显示，来完成操作。有时候有些信息我们需要传给js，但是又不想给用户看，所以也会隐藏起来。

## display/visibility方法

应用方法：

```
1.<input name="customDayCondition" style="visibility:hidden;"/>

2.<input name="customDayCondition" style="display：none"/>
```

注意两种样式：

两种样式都可以隐藏标签元素，区别在于：

第一种隐藏只能隐藏元素，但隐藏标签的大小所占的位置会一直存在。仅仅是不可见了。但是页面上所占的位置还是它自己的，不会被其他元素所用掉。

第二种隐藏不仅能隐藏元素，还可以隐藏标签所占位置的大小。排版的元素会依次移动把之前元素所占空间全部用掉。

## jquery的hide()和show()

在js中jquery提供了hide()和show()方法可以控制元素或标签的显示或隐藏。

用法如下：

 <script type="text/javascript">  
   $("input[name='customDayCondition']").hide();  
 </script>

这样就OK了。
